# 第二版胸片分类训练配置

第二版从 `pretrain_model/yolo26x-cls.pt` 重新微调，入口为根目录 train.py。训练目录为 `outputs/train/ncccu_cls_v2_512`，预测目录为 `outputs/predict/ncccu_cls_v2_512_test`。原版训练记录作为基线，最佳验证 Macro-AUC 为 0.775180。

## 为什么调整

第一版实际采用 224 输入、batch=128、AdamW lr0=0.001、1000 轮余弦周期、patience=50，关闭随机增强且 dropout=0。第 4 轮达到最佳 AUC，第 54 轮训练 BCE 降至 0.00213、验证 BCE 升至 1.10447，符合明显过拟合的表现。最后学习率仍为初始值的约 99.29%，调度周期不匹配实际训练时长。

30,344 张训练影像对应 18,513 次检查、11,055 名患者，并不等于 30,344 个独立患者。第一版每轮约 238 次优化器更新，4 轮约 952 次更新、121,376 次影像呈现；预训练网络在几轮内出现最佳验证值并非不可能。验证集 859 次检查来自 228 名患者，指标也可能受患者与少数类分布影响。

[CheXpert 原论文](https://arxiv.org/pdf/1901.07031) 使用 Adam、学习率 1e-4、batch=16、320 输入，并在约 22 万张影像的数据集上训练 3 轮。这是较低微调学习率的参考，不是本项目最优参数的证明，也不代表不同网络、数据和梯度累积下的训练轮数可以直接比较。本项目继续使用合规的非医学预训练权重。

## 参数对照

| 参数 | 第一版实际训练 | 第二版 | 调整目的 |
| --- | --- | --- | --- |
| model | yolo26x-cls.pt | yolo26x-cls.pt | 保持骨干模型 |
| imgsz | 224 | 512 | 提高输入细节，继续等比例缩放与填充 |
| batch | 128 | 16 | 为高分辨率保留显存空间 |
| nbs | 64，实际每次更新 128 张 | 128，每 8 个微批累积 | 保持完整累积组的名义样本量 128 |
| optimizer | AdamW | AdamW | 保持优化器 |
| lr0 | 0.001 | 0.0001 | 降低微调强度 |
| warmup_bias_lr | 0.001 | 0.0001 | 偏置预热与新学习率匹配 |
| warmup_epochs | 3 | 3 | 保留预热 |
| epochs | 1000 | 40 | 在实际训练时长内进行明显衰减 |
| cos_lr / lrf | True / 0.01 | True / 0.01 | 目标末期学习率约 1e-6 |
| patience | 50 | 12 | 控制长期验证停滞后的训练成本 |
| dropout | 0 | 0.2 | 分类头正则化 |
| hsv_v | 0 | 0.1 | 每次读取做 [0.9,1.1] 倍亮度扰动 |
| weight_decay | 0.0005 | 0.0005 | 保留原权重衰减，避免同时大幅加强所有正则项 |
| save_period | 10 | 5 | 更密集保留阶段检查点 |
| workers | 6 | 6 | 沿用本机设置 |

梯度累积不等价于真实 batch=128：BatchNorm 仍按 16 张微批统计，最后一组按实际样本数归一化。降低学习率同时也会降低 AdamW 每步解耦权重衰减的绝对幅度，因此不声称单靠学习率下降已经加强了全部正则化。

保持 deterministic=True、seed=0、AMP=True。确定性不等于禁止随机增强：亮度扰动和 Dropout 的随机状态已经纳入播种和检查点，重复运行及断点恢复仍可复现。随机裁剪、左右/上下翻转、色相饱和度扰动、强自动增强和随机擦除继续关闭，保持胸部完整视野与解剖方向。现有 BCE、类别映射、全部官方样本、Study 聚合和 Macro-AUC 选模保持一致。

[Ultralytics 分类文档](https://docs.ultralytics.com/tasks/classify) 说明 224 是分类预训练评测尺寸，并允许定制保持全图的预处理；[胸片分辨率研究](https://pubmed.ncbi.nlm.nih.gov/37547812/) 显示不同疾病对尺度的需求不同。512 是本次验证候选，不保证越大越好。[Ultralytics 训练参数文档](https://docs.ultralytics.com/modes/train) 提供 dropout 等分类正则化参数的定义。

这是同时调整多个参数的工程迭代，不是单变量消融。若成绩提升，不能将全部收益归于某个参数；若未提升，应比较学习率、分辨率、Dropout 和亮度扰动的独立对照。

## 运行和评估

在 PyCharm 运行 train.py，或执行：

```powershell
uv run --no-sync python train.py
```

保留 resume=False。用第一版 last.pt 续训会继承第一版超参数，而且原任务已经触发早停。第二版中断后才使用第二版 last.pt 进行恢复，并设置新的输出 name。

512 的完整训练与验证 RGB uint8 磁盘缓存约 23.3 GiB，此外需要检查点与日志空间。首次启动仍需完成预缓存，控制台会显示进度。验证使用固定预处理，不使用训练中的亮度扰动和 Dropout。

第二版训练完成后，predict.py 已对应第二版 best.pt、512 输入和 512 导出尺寸。当前 gate=0.5 用作默认值，须重新用第二版 valid 概率估计阈值。原版 0.0684555 及逐类阈值不能直接迁移。使用 tools/analyze_training.py 时，将入口的 training_run 改为 `./outputs/train/ncccu_cls_v2_512`，并设置新的分析 name。

完整训练后比较最佳 Macro-AUC 是否超过 0.775180、验证损失是否持续恶化、逐类 AUC 是否改善；不能仅以“最佳轮次更晚”或“训练损失下降更慢”判断成功。第二版完整训练和最终分数尚未执行或验证。
