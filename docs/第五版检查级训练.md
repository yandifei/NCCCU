# 第五版检查级训练

在 PyCharm 运行根目录 `train.py`，或执行 `uv run --no-sync python train.py`。当前默认运行名为 `v5_study_mean_512`，从原 ImageNet 权重开始，使用 512 输入、FP32、`lr0=3e-5`、16 轮调度、1 轮预热和早停耐心 6。训练产物位于 `outputs/train/<name>/`。

| 实验 | `objective` | 训练损失 | `batch` / `nbs` 单位 |
| --- | --- | --- | --- |
| v4 基线 | `image` | 每张图计算 BCE，影像等权 | 影像 |
| v5-A | `study_weighted` | 每张图计算 BCE，乘以 `影像总数 / (检查总数 × 本检查视图数)` | 影像 |
| v5-B | `study_mean` | 对检查内全部视图的 sigmoid 概率取均值，再按检查计算一次 BCE | 检查 |

v5-B 逐检查前向和反传，在累积组内按实际检查数归一化。当前 `batch=8`、`nbs=128` 对应 128 次检查一次更新，和逐图模式的每轮更新次数有差异。验证和预测均按检查平均全部视图的概率。分辨率对照可将 `imgsz` 改为 640，并指定新的运行名。续训使用同一次运行的 `weights/last.pt` 和 `resume=True`，训练目标随原配置恢复。

`results.csv` 中 `val_loss` 为逐图 BCE，`study_val_loss` 为聚合后的检查 BCE。按验证 Macro-AUC 选出的最佳轮另存 `best_validation.json` 和 `best_validation.npz`。预测入口默认读取 v5-B 的 `best.pt`，尺寸由权重决定。`split="valid"` 输出验证概率和报告，`split="test"` 输出官方格式 CSV 并调用打包入口。

v5-A 的最佳验证 Macro-AUC 为 0.79208，v4 为 0.79335，v3 为 0.79437。运行 `uv run --no-sync python tools/compare_predictions.py`，以相同验证检查对齐两份概率，再按患者配对重采样，报告逐类差值和 95% 区间。默认输入为本地 v4 验证预测及 v5-A 的最佳轮。区间衡量这批验证患者的抽样不确定性，验证集选模仍会影响估计。

2026-11-12 对 228 名患者、859 次检查做 2,000 次配对重采样，v5-A 减 v4 的 Macro-AUC 为 −0.00127，95% 区间为 [−0.00703, +0.00546]。报告位于 `outputs/analysis/v5a_vs_v4/comparison.json`。

执行 `.venv/Scripts/python.exe -m unittest discover -s tests`，25 项通过，覆盖轮次续训、数据读取和打包校验。执行 `.venv/Scripts/python.exe tools/verify_pipeline.py`，v5-B 两轮 512 FP32 小规模训练及验证预测成功，峰值保留显存约 3.86 GiB。完整 v5-B 训练分数待正式运行确认。
