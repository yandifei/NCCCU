# 第六版分辨率对照

第六版用 `v6_convnext_small_640` 对照第三版 `v3_convnext_small_512`。两次运行的训练参数仅运行名和输入尺寸不同，旧配置缺省的 `objective` 对应 `image`。当前实现的逐图 BCE 使用分步求均值，与历史版本的直接求均值在数学上等价，浮点舍入可能不同。

训练采用 ConvNeXt-Small、同一 ImageNet 初始化、逐图 BCE、AMP、微批 8、累积目标 128、学习率 `1e-4`、3 轮预热、40 轮余弦周期和早停耐心 12。保持整张影像的宽高比并填充至 640。训练入口为 `train.py`，预测和阈值分析入口读取本次运行的 `best.pt`，推理尺寸由权重决定。

正式结果以官方验证集的 Study Macro-AUC 为主，与第三版最佳值 `0.7943713133` 比较。记录逐类 AUC，特别关注肺部阴影和肺炎。若峰值提高，再检查同批患者的配对差值及 T4 单图端到端耗时。若完整训练需要降低微批量，使用同一较小微批量补跑 512 对照。

2026-11-12 执行 `.venv/Scripts/python.exe tools/verify_pipeline.py`，两轮 640 AMP 小规模训练、验证和 FP32 预测通过，峰值保留显存约 7.16 GiB。正式训练日志写入 `outputs/v6_convnext_small_640.log`，每轮指标写入 `outputs/train/v6_convnext_small_640/results.csv`。
