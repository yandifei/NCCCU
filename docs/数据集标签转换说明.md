# 数据集标签转换说明（CSV → 逐图 txt）

> 对应脚本：[tools/csv2txt.py](../tools/csv2txt.py)
> 适用数据：`datasets/{train,valid}.csv` + `datasets/{split}/{Subject_id}/{Study_id}/{Dicom_id}.jpg`
> 生成结果：`datasets/labels/`（每图一个 txt 标签，供自定义多标签 Dataset 使用）

## 一、做什么

把 CSV 里的 `Predict_class`（分号分隔，如 `1;8;9;4`）转成每张图一个 `.txt` 标签文件。
本任务是**多标签分类**（一张图可同时有多个病），不是检测，标签里没有 bbox。

## 二、命令

```bash
python tools/csv2txt.py                    # 转换 train + valid（默认）
python tools/csv2txt.py --dry-run          # 只统计，不写文件
python tools/csv2txt.py --splits train     # 只转 train
python tools/csv2txt.py --limit 100        # 试跑前 100 行
python tools/csv2txt.py --one-per-line     # 每个类别一行（默认一行空格分隔）
python tools/csv2txt.py --id-base 1        # 保留原始 1..10（默认转 0..9）
```

## 三、输入结构

```text
datasets/
├── train.csv / valid.csv / test.csv     # test.csv 无标签列
├── train/{Subject_id}/{Study_id}/{Dicom_id}.jpg
└── valid/{Subject_id}/{Study_id}/{Dicom_id}.jpg
```

一幅图一行，`Predict_class` 是**多标签**（可共现），不是检测框。

## 四、输出结构

```text
datasets/labels/
├── classes.txt                 # 10 行类别名，行号=索引（0..9）
├── train_manifest.csv          # 图片↔标签↔原始标签 索引表
├── valid_manifest.csv
├── train/{Subject_id}/{Study_id}/{Dicom_id}.txt
└── valid/{Subject_id}/{Study_id}/{Dicom_id}.txt
```

## 六、⚠️ 这些 txt 不能直接喂给 Ultralytics 原生任务

- **detect / segment / pose / obb**：需要 bbox / mask / 关键点 / 旋转框标注，本赛数据只有图像级多标签，**无法训练**；
- **classify（`yolo26*-cls`）**：官方只认 ImageFolder（`train/<类名>/<图>`，一图一标签，softmax），
  读不了本脚本的 txt，也表达不了「一张图多个类别」；
- 正确做法：用 `-cls` 权重作骨干 + 自定义 Dataset（读 txt → 10 维 multi-hot）+ 10 维 sigmoid 头 + BCE/ASL 损失，
  按 Macro-AUC 选模。方案细节见 [赛题技术分析](比赛资料/赛题技术分析-YOLO任务类型判断.md)。

## 七、`datasets/data.yaml` 是本项目的自定义配置

该文件已改写为本赛题配置：`task: multi_label_classification`、`nc: 10`、官方 id 1–10 ↔ 索引 0–9 映射、
影像 / 标签 / CSV 路径、2026-11-07 实测规模，以及按 Study 聚合、10 列概率、Macro-AUC 的提交约定。
消费者是本项目的**自定义多标签 Dataset**，不是 Ultralytics。

它**不能**直接传给 `yolo` 的任何一个原生任务：

- **detect / segment / pose / obb**：标签必须是 bbox / 多边形，本赛只有图像级多标签；
- **classify（`yolo26*-cls`）**：`data=` 只接 ImageFolder 目录，不读 yaml，且一图只能一个类别；
- 当前 Ultralytics 8.4.204 没有多标签分类任务，源码中不存在 multi-label 支持。
