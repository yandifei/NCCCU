# 代码重构与训练记录

## 模块职责

本次保留目录布局和根目录显式参数入口，使用四空格缩进、类型注解、中文说明及 pathlib 路径。训练继续使用 ConvNeXt-Small、逐图 BCE 和 Study 等权概率均值。

| 模块 | 职责 |
| --- | --- |
| `src/ncccu/configuration.py` | 显式训练与预测配置、类型及范围校验、普通字典序列化 |
| `src/ncccu/data.py` | 官方 CSV 校验、类别映射、图像预处理和 Dataset |
| `src/ncccu/evaluation.py` | 批次推理、Study 聚合、AUC 和 F1 |
| `src/ncccu/training.py` | 配置解析、单轮优化、验证、选模、检查点及恢复 |
| `src/ncccu/model.py` | ImageNet 初始化、模型加载和检查点结构校验 |
| `src/ncccu/runtime.py` | 输出目录、随机状态、文件摘要和曲线 |
| `src/ncccu/submission.py` | 预测与测速共用的 CSV 写入 |
| `src/ncccu/multilabel.py` | 旧导入路径的兼容导出 |

`tools/check_dataset.py` 与训练共用数据校验。打包流程拆分为输入校验、归档配置准备和原子发布。新预测记录保存 `model_sha256`；打包核对摘要及归档内模型内容，拒绝把被后续训练覆写的权重与旧预测混用。旧记录没有摘要时仍可读取，但不能据此证明权重内容未变。包内推理入口不会把摘要当成模型参数传入。

保留旧 ConvNeXt 检查点格式、轮次种子、梯度累积尾组归一化、选模及早停规则。参数仍在 `train.py` 和 `predict.py` 中直接修改。阈值分析脚本主体沿用原实现，本次仅整理阈值模块并明确广播校验。
