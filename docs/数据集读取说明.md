# 官方多标签数据读取约定

训练和验证直接读取官方 CSV。现有影像按下面的路径定位。

```text
datasets/
├── train.csv
├── valid.csv
├── test.csv
├── train/{Subject_id}/{Study_id}/{Dicom_id}.jpg
├── valid/{Subject_id}/{Study_id}/{Dicom_id}.jpg
└── test/{Subject_id}/{Study_id}/{Dicom_id}.jpg
```

CSV 的 `Predict_class` 是以分号分隔的官方类别 ID。例如 `1;8;9;4` 对应内部索引 `0, 7, 8, 3`，训练目标为 `[1,0,0,1,0,0,0,1,1,0]`。类别顺序见根目录 README 的十类表。Dataset 应在读取时构造 10 维浮点 multi-hot 向量。

`test.csv` 无标签列，仅用于推理。保留 Subject_id 和 Study_id，推理后按检查聚合各张影像的概率。完整保留官方样本与划分。

数据准备只需运行只读检查。

```powershell
uv run --no-sync python tools/check_dataset.py
```

脚本检查三个 CSV 的必需列、重复影像记录、影像文件存在性，以及训练和验证标签的范围、重复和空值。失败返回非零退出码。它检查文件路径，影像解码仍由后续 Dataset 验证。

此前的自定义 YAML 和 TXT 转换脚本已移除。已有 `datasets/labels/` 属于历史派生产物，官方 CSV 读取流程不依赖它。

训练入口和自定义 Dataset 尚待实现。YOLO 分类预训练权重可用于初始化模型，训练时需要 10 维 logits、BCEWithLogitsLoss，预测使用逐类 sigmoid。官方 CSV 需要由自定义训练代码读取。
