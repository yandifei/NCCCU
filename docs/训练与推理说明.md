# 多标签训练与推理

train.py 和 predict.py 使用直接填写参数的入口调用，运行前在编辑器中修改参数及旁边的中文注释。多标签训练循环位于 src/ncccu/training.py，推理逻辑位于 src/ncccu/inference.py。两份入口都保留 Windows 多进程保护。

## 启动训练

在 train.py 中设置 model、data、epochs、imgsz、batch、device 等参数，然后直接运行。

~~~powershell
uv run --no-sync python train.py
~~~

model 默认指向 pretrain_model/yolo26n-cls.pt，data 指向官方 CSV 和影像目录。相对路径以项目根目录为基准。device=0 使用 PyTorch 的第一张显卡，device="cpu" 使用 CPU。

默认 AdamW、lr0=0.001、weight_decay=0.0005、余弦学习率调度、patience=20。amp=True 在 CUDA 上启用混合精度，workers 设置数据加载进程数。训练和推理统一使用 RGB、等比例缩放、114 填充值和除以 255 的处理。当前未添加随机增强。

训练使用 10 维 multi-hot 与 BCEWithLogitsLoss。验证按 Subject_id / Study_id 取概率均值，以 Macro-AUC 选模，记录阈值 0.5 下的 Macro-F1。完整训练要求验证集全部 10 类均有正负样本。

产出统一位于 outputs/train/<name>/。name=None 自动生成时间戳目录，指定已有目录名会报错。

- weights/last.pt 包含最后完成轮次的模型、优化器、学习率调度器、AMP scaler、随机数状态、早停计数、训练配置、指标历史和历史最佳模型。
- weights/best.pt 用于推理，保存最佳验证 Macro-AUC 对应模型。
- args.json 保存本次运行参数。
- results.csv 保存已完成轮次的指标。

## 断点继续训练

在 train.py 的入口调用中修改以下两项。

~~~python
model=r"./outputs/train/上次训练目录/weights/last.pt",
resume=True,
~~~

恢复最近完整保存的轮次，从下一轮继续。中断时尚未完成的轮次会重新训练。模型、优化器、学习率、AMP、随机数状态、最佳分数和早停计数一起恢复。

续训沿用检查点中的原定总轮数、批量大小、输入尺寸、学习率、dropout、patience、seed 和 smoke_test 等训练参数。data、device、workers、name 可在当前入口指定，其中 device 必须与原任务保持同一设备类型。数据路径可以迁移，但应指向同一份官方数据。

续训创建新的 outputs/train/<name>/ 目录，并继承此前指标和最佳权重。name=None 可直接生成新目录。已达到总轮数或已触发早停的任务会明确报错，避免误以为仍在续训。

旧版本只保存模型的 last.pt、以及 best.pt，仍可用于预测，但缺少优化器状态，无法完整续训。需要本次更新后生成的 last.pt。检查点通过临时文件写入后替换，保存中断时可继续使用此前已完成的检查点。

## 启动预测

在 predict.py 中填写 model 为实际的 best.pt 路径，再直接运行。

~~~powershell
uv run --no-sync python predict.py
~~~

split="test" 读取官方测试集，亦可设置为 train 或 valid。batch、device、workers、gate 和 name 都在入口代码中直接修改。输入尺寸由权重读取。

输出位于 outputs/predict/<name>/submission.csv，每次检查 10 行，列为 Subject_id、Study_id、Predict_class、Probability、Gate。预测使用逐类 sigmoid，按检查求均值。gate 默认 0.5，只写入阈值列，始终输出全部 10 类概率。提交前仍需核对平台最终模板。

## 验证

将 train.py 的 smoke_test 设为 True、epochs 设为 1、imgsz 设为 64、batch 设为 4，可以对前 16 次完整检查进行流程验证。预测冒烟权重时，同样需要在 predict.py 设置 smoke_test=True，结果为 smoke_predictions.csv。这些权重仅用于检查代码流程。

~~~powershell
uv run --no-sync python -m unittest discover -s tests
~~~

测试覆盖标签和指标，以及真实 YOLO 模型在临时样例上的连续两轮训练、第二轮中断后恢复、最佳权重预测。CPU 对照测试要求恢复后的参数逐项完全相等，同时核对学习率调度和指标历史。GPU 下的浮点计算仍可能存在非确定性。
