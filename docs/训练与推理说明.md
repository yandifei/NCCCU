# 多标签训练与推理

train.py 和 predict.py 中的参数均作为实参传入，直接在编辑器中修改后运行。入口保留 Windows 多进程保护，核心代码位于 src/ncccu/。未知参数和违反多标签约束的参数会立即报错。

## 当前启用配置

训练默认使用 yolo26x-cls、100 轮、224 输入、batch=16、workers=3、CUDA 设备 0、FP16 AMP、AdamW 和余弦学习率。初始学习率 0.001，预热 3 轮，patience=20。

deterministic=True 启用严格确定性算法，设置 cuBLAS 工作区、关闭 cuDNN benchmark 和 TF32，并统一 Python、NumPy、PyTorch 及数据加载进程的随机种子。随机数状态保存在断点中。确定性要求保持同样的硬件、软件、数据和配置；PyTorch 遇到无法提供确定性实现的算子会报错。[PyTorch 确定性算法说明](https://docs.pytorch.org/docs/main/generated/torch.use_deterministic_algorithms.html)

所有影像以 RGB 等比例缩放、114 填充和除以 255 的方式读取。默认随机增强参数均为零或 None，保留完整胸片。fliplr、flipud、HSV 扰动、scale、auto_augment 和 erasing 已接入，可按需修改；开启随机增强后仍使用已保存的随机数状态。自动增强与 HSV 扰动同时配置会报错。

## 启动训练

~~~powershell
uv run --no-sync python train.py
~~~

默认产出目录为 outputs/train/ncccu_cls，已有目录会报错。重新训练或续训时修改 name，也可设为 None 自动生成时间戳。

- save=True 每轮保存 weights/last.pt 和历史最优 weights/best.pt。
- save_period=10 每 10 轮额外保存 weights/epochN.pt。
- plots=True 生成 results.png 和首批影像 train_batch0.jpg。
- cache="disk" 将缩放后的影像缓存到本次运行的 cache/，完整数据集会占用额外磁盘空间。也支持 False、True 或 "ram"。
- args.json 保存参数，results.csv 保存完整轮次指标。
- project 和 save_dir 可调整产出位置，路径必须位于 outputs 内。

训练直接读取官方 CSV，使用 10 维 multi-hot 和 BCEWithLogitsLoss。验证按检查聚合概率，以 Macro-AUC 选模，记录 Macro-F1。正式训练固定使用全部样本和官方 valid 验证集。

optimizer 显式支持 AdamW、Adam、SGD、RMSProp；momentum 对 Adam 系列控制 beta1。cos_lr=False 使用线性衰减。warmup_epochs、warmup_momentum 和 warmup_bias_lr 控制逐批预热。nbs 控制梯度累积目标批量，按完整微批向上取整，尾批按真实样本数归一化。

freeze 指定冻结的前 N 层，冻结层的 BatchNorm 同时保持评估模式。pretrained=False 根据同一结构随机初始化。cls 控制总 BCE 权重，cls_pw 控制正例加权幂。channels_last 控制模型及输入内存格式。time 为本次运行的小时上限，在完成一轮并保存后检查。

## 启动阶段与缓存进度

cache="disk" 或 "ram" 会在第一轮训练前逐张解码、缩放全部训练和验证影像。此阶段由 CPU 和磁盘处理，GPU 利用率通常很低。workers 控制之后的批次加载进程数，预缓存目前由主进程执行。

verbose=True 时，程序立即报告启动、CSV 检查、模型加载和输出位置。缓存阶段约每 5 秒打印一次数量、百分比、速度及预计剩余秒数，首张和完成时也会输出。进入训练、验证与权重保存时均有阶段提示。

日志修复对新启动的进程生效，已经运行的旧进程继续执行原来的代码。可以查看 outputs/train/<name>/cache/train 和 cache/valid 中的 .npy 文件数量是否持续增加，以确认现有进程的进度。每次运行创建独立缓存。

验证缓存日志使用以下命令，覆盖开始提示、定时进度、完成提示以及关闭缓存时的说明。

~~~powershell
uv run --no-sync python -m unittest discover -s tests -p test_cache_progress.py
~~~

## 断点续训

修改 train.py 中的配置。

~~~python
model="./outputs/train/ncccu_cls/weights/last.pt",
resume=True,
name="ncccu_cls_resume",
~~~

last.pt 保存模型、优化器、调度器、AMP scaler、随机数、早停计数、参数、指标历史和最佳模型。恢复从最后完整轮次的下一轮开始，中断轮次重新执行。续训创建新目录并继承历史结果。

训练超参数从检查点恢复。data、device、workers、name、project 和 save_dir 可以在入口指定；数据应保持相同，设备类型应与原任务一致。已完成总轮数或触发早停的任务会报错。

旧版包含训练状态的检查点会按原来的单组 AdamW 和无预热方案恢复。更早的纯模型权重以及 best.pt 仅支持推理。检查点写入采用临时文件替换。

## 启动预测

默认权重路径与默认训练目录对应。

~~~powershell
uv run --no-sync python predict.py
~~~

source 指向 data/split 对应的官方 CSV。切换 split="valid" 时，同时修改 source。imgsz 须与检查点一致，或设为 None 从权重读取。

默认使用 FP32，quantize=16 可在 CUDA 上使用 FP16。augment=True 对原图和水平翻转图的 sigmoid 概率取均值。最终按 Subject_id / Study_id 聚合，同一检查输出全部 10 类概率。

产出位于 outputs/predict/ncccu_cls_test。

- submission.csv 包含 Subject_id、Study_id、Predict_class、Probability、Gate，每次检查 10 行。
- save=True 保存带概率文字的逐图 JPG。
- save_txt=True 保存达到 gate 阈值的官方类别 ID；save_conf=True 同时保存概率。
- show 控制预览窗口；show_labels、show_conf 和 plot_options 控制文字绘制。plot_options 中同名开关与外层开关均开启时生效。
- 默认字体为 PIL 内置 default，亦可填写本地字体文件路径。
- export_options.enabled=True 导出 model.torchscript，输出为 10 类独立 sigmoid 概率；当前支持固定输入、FP32 TorchScript。导出会比对示例输入的原模型和导出模型结果。

当前 Python 3.15 环境中，TorchScript 导出实测成功，但 PyTorch 会提示 torch.jit.trace 在 Python 3.14+ 不受官方支持。可以将 export_options.enabled=False 关闭此额外产物。ONNX、TensorRT 等其他格式当前会报错，需单独实现并验证部署链路。

## 参数适用范围

两份文档的参数均在入口中显式传入。多标签任务不使用的检测框、分割、姿态、视频和 NMS 等参数设为禁用值，由配置校验强制执行。筛选类别、合并为单类、改用测试集验证等操作也会报错。

compile、切片、蒸馏、QAT、自动批量、动态导出等功能尚未接入，当前要求明确的关闭配置。其余已接入参数使用本项目说明中的输入形式，部分范围小于 Ultralytics 原生接口，例如 batch 使用正整数、amp 使用布尔值、freeze 使用层数整数。

## 验证

~~~powershell
uv run --no-sync python -m unittest discover -s tests
~~~

八项测试覆盖标签、指标、断点恢复、参数校验、缓存、周期权重、曲线、图片/TXT、TorchScript 和重复预测。RTX 5080 测试启用 AMP、严格确定性和 workers=3，两次独立训练及恢复训练的权重和指标逐项完全相等。GPU 测试需要本地官方数据与预训练权重，否则跳过。

smoke_test=True 使用前 16 次完整检查验证流程，此时预测也需要 smoke_test=True，结果为 smoke_predictions.csv。正式全量精度和赛事 T4 延迟尚未验证。
