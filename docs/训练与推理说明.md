# 多标签训练与推理

本项目参考分类训练与预测参数文档，使用 Ultralytics 加载 YOLO 分类骨干，自定义 PyTorch 训练循环直接读取官方 CSV。训练目标为 10 维 multi-hot，损失为 BCEWithLogitsLoss，推理对 logits 逐类取 sigmoid。官方参数表中的全部选项并未逐项实现，实际支持项以两个入口的 --help 为准。

## 训练

~~~powershell
uv run --no-sync python train.py --name baseline --epochs 100 --imgsz 224 --batch 16 --device 0
~~~

默认权重位于 pretrain_model/yolo26n-cls.pt，可用 --model 切换本地其他大小的分类模型。--data 指向包含三个官方 CSV 和影像子目录的 datasets 文件夹。

默认 AdamW、lr0=0.001、weight_decay=0.0005、余弦学习率衰减至初始值的 0.01、patience=20、dropout=0、seed=0、workers=0。CUDA 上默认启用 AMP，可用 --no-amp 关闭。固定种子便于对比，GPU 运算仍可能存在数值非确定性。当前使用完整影像等比例缩放和填充至正方形，RGB 三通道除以 255；训练、验证、预测共用此变换，当前未加入随机数据增强。

验证先对同一 Subject_id / Study_id 的概率取均值，再计算 Macro-AUC 和阈值 0.5 的 Macro-F1。仅 Macro-AUC 用于选模和早停。正式验证要求 10 类均有正负样本，同一检查的标签须一致。

每次训练写入 outputs/train/<name>/，已有目录会报错，省略 --name 自动使用时间戳。

- weights/best.pt 保存最佳验证 Macro-AUC 权重。
- weights/last.pt 保存最后完成的轮次权重。
- args.json 保存运行参数。
- results.csv 记录逐轮损失、Macro-AUC、可计算 AUC 类别数和 Macro-F1。

权重包含模型结构、类别顺序和预处理尺寸，可独立用于预测。当前检查点用于推理，不包含优化器状态，暂不支持断点续训。

## 预测

~~~powershell
uv run --no-sync python predict.py --model outputs/train/baseline/weights/best.pt --name baseline_test
~~~

默认读取官方 test.csv。可用 --split valid 验证验证集输出，--batch 调整推理批量，--device cpu 使用 CPU。预处理尺寸从权重读取，输出按检查取均值，--gate 默认 0.5。此阈值只写入 Gate 列，全部 10 类概率都会输出。

结果写入 outputs/predict/<name>/submission.csv，列为 Subject_id、Study_id、Predict_class、Probability、Gate，每次检查 10 行，类别 ID 为 1–10。该 CSV 仍需与平台最终模板核对，尤其是 Subject_id 列。args.json 保存推理参数。预测使用 FP32。

## 流程验证

~~~powershell
uv run --no-sync python train.py --epochs 1 --batch 4 --imgsz 64 --smoke-test --name smoke_multilabel
uv run --no-sync python predict.py --model outputs/train/smoke_multilabel/weights/best.pt --split valid --smoke-test --name smoke_multilabel
uv run --no-sync python -m unittest discover -s tests
~~~

冒烟模式读取各划分前 16 次完整检查，仅用于程序验证。输出权重带有冒烟标记，预测时必须显式传入 --smoke-test，结果命名为 smoke_predictions.csv。少量检查可能没有某类别正例或负例，冒烟指标仅对可计算类别求均值，不能代表正式成绩。
