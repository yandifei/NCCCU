# 赛事提交打包

在根目录 push.py 中填写队伍名并选择实际获得历史最高分的预测目录、submission.csv 和对应模型。可以直接在 PyCharm 运行 push.py，或在仓库根目录运行：

```powershell
uv run --no-sync python push.py
```

| 配置 | 用途 |
| --- | --- |
| training_run | 训练目录，读取实际训练参数 args.json |
| model | 该次正式预测实际使用的最终权重，通常是 weights/best.pt |
| prediction_run | 正式测试集预测目录，读取实际预测参数 args.json |
| submission | 历史最高分对应的原始 CSV，打包时逐字节保留 |
| pretrain_model / licenses | 实际使用的公开预训练权重和对应的许可证全文 |
| cost_script | 符合赛事要求的耗时测试脚本，须复用提交版本的推理逻辑 |
| declaration | 使用官网下载的模板填写并保存的模型核验材料与数据申明清单 |
| output_dir | ZIP 输出目录，默认 outputs/submission |

正式预测前，在 predict.py 中核对 model、imgsz 和实际选用的权重是否对应。当前 push.py 示例中的训练目录是 outputs/train/v2_512。如果使用它的权重，predict.py 的 model 应指向该目录的 weights/best.pt。运行 predict.py 生成 submission.csv 和 args.json，再填写对应的 prediction_run。

打包器检查文件存在性、训练和预测记录中的权重路径、最终推理权重的 500 MB 上限，以及 CSV 是否为每次官方测试检查提供了恰好十类的有效概率。ZIP 的 code/ 包含根据运行记录生成的入口、src/ncccu、requirements.txt、pyproject.toml 和 uv.lock。包内入口从解压目录读取权重，复核时将官方数据放到解压根目录的 datasets。该项目使用的最终推理产物是单个 PyTorch 权重，包内预测入口关闭额外图片、TXT 和模型导出。

ZIP 还包含 model/、pretrain_model/、licenses/、根目录 cost.py、核验表和 submission.csv。模型缓存、训练断点、原始影像和数据集 CSV 均通过显式文件清单排除。打包结束打印预训练权重 SHA-256，便于核对声明表。脚本不覆盖已有同名 ZIP。

cost.py 与填写后的核验表须由实际提交方准备。脚本检查 XLSX 文件结构，申报内容、公开链接可访问性、测速一致性和官方 Python 3.12 / T4 环境的兼容性仍需实测核对。requirements.txt 按仓库锁文件记录本地直接依赖版本。赛事网站分别接收评分 CSV 和合规 ZIP，push.py 负责生成本地 ZIP。
